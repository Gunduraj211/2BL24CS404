## Problem Statement
Build a Maintenance Mode application using ServletContext. Configure a context-param in web.xml called maintenanceMode (values: true/false) and a maintenanceMessage. The Servlet reads the flag. If true, display the maintenance banner instead of normal content. If false, show a normal welcome page.
## Technologies Used
- Java (Servlets)
- HTML, CSS (inline)
- Apache Tomcat 10
- Eclipse IDE
## How to Run This Project
1. Clone this repository or download the ZIP.
2. Import the project into Eclipse as a Dynamic Web Project.
3. Add Apache Tomcat as the server in Eclipse.
4. Right-click project → Run As → Run on Server.
5. Open browser and go to: http://localhost:8080/MaintenanceApp0/
